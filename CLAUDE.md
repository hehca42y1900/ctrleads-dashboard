# Правила для дашбордов (читать перед правкой любой страницы)

Формулы — одинаковые во всех дашбордах продавцов (VB, Теплоэксперт, основной `index.html`, новые):

- **Маржа** = чистая прибыль / итого доходов (Акт + выкупы + компенсации + баллы).
- **ROI (рентабельность)** = чистая прибыль / себестоимость. Маржу не подписывать «Рентабельностью».
- **% выкупа** = (заказано − отмены и возвраты) / заказано (10 заказали, 2 вернули = 80%).
  Считать по отчёту «Начисления» Ozon: заказано = шт со строкой «Логистика» (минус
  «Логистика - отмена начисления»), отмены/возвраты = шт с «Обратной логистикой».
  НЕ из Акта реализации и НЕ из файла заказов. Общий % — на «Обзоре», по артикулу — в «Товарах».
  Образец — `cabinet/teploexpert/`, коммит `17b0a86`.
- Налог ОСНО «НДС к вычету» = (реализовано − себестоимость) × 22%, без деления на 1,22.

## Отчёты Ozon и WB меняются — обновлять разбор под каждый новый формат (правило владельца, 2026-10-23)

WB и Ozon регулярно переименовывают колонки, добавляют листы и выпускают отчёты в новом виде. Когда владелец присылает
свежие выгрузки — прогнать их через разбор страницы (headless) и сверить колонки; если формат изменился, обновить разбор
сразу, не спрашивая. Колонки искать по названию, держать старое и новое название, при отсутствии колонки — явное
сообщение на странице, а не тихий ноль.

Обновлено 23.10.2026 («Юнит-экономика», вид WB; скрипт правки — `marketing-social-skills`, ветка
`claude/demo-site-nuqsd3`, `demo-site/wb_parser_update.py`):
- логистика: WB переименовал колонку в «Возмещение издержек по перемещению и операционной обработке товара»;
- новая «Воронка продаж»: лист «Товары», заголовки во 2-й строке, «Артикул WB» / «Заказали товаров, шт» / «Средняя цена, ₽»,
  в ней же остатки (файл «Цены» не обязателен);
- из «Детализации» теперь читаются «Хранение» по артикулам (ручной ввод — только если колонки нет), «Услуга по обработке
  Товара», программа лояльности (участие + баллы − компенсация), «Удержания»;
- маржа больше не подписана «Рентабельностью», добавлен ROI.
